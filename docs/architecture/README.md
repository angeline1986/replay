# Notas históricas da importação imediata

Os arquivos desta pasta registram propostas e verificações feitas durante a implementação inicial. Trechos que dizem que a interface, a função ou a migration ainda não foram publicadas descrevem o estado daquela fase e não o estado atual do RePlay.

Para consultar o comportamento atual, use o código em `src/`, a função em `supabase/functions/import-channel/` e a migration `supabase/migrations/20261107222904_replay_immediate_import.sql`. O arquivo `replay-import-guard.proposal.sql` é apenas uma proposta antiga; não deve ser executado como migration.
